## RU 🎉Теперь в альфа тесте

# Что такое Project Alpha?

**Project Alpha** - это умный планировщик задач и ваш помощник для организации планов дел. 

# Зачем он нужен?

Данное приложение поможет вам не забыть важное событие. С его помощью вы можете записать важное(или не очень) событие, а приложение подскажет если есть запланированные дела.

# Техническое задание:
1. Меню приложения - ✅
2. Виджет создания задач - ✅
3. Функциональное меню настроек - ✅
4. Создание, открытие, редактирование файла настроек - ✅
5. Создание, открытие, редактирование базы данных с задачами - ✅
6. Возможность менять язык приложения - ✅
7. Возможность поменять тему - ✅

**Для настройки виртуальной среды используйте следующие команды:**

1. python -m venv .venv
2. .venv\Scripts\activate
3. pip install PyQT6


## EN 🎉Now in alpha testing

# What is Project Alpha?

**Project Alpha** is a smart task planner and your assistant for organizing your to-do list.

# Why do you need it?

This app will help you remember important events. You can use it to jot down important (or not so important) events, and the app will notify you if you have any upcoming events.

6. Ability to Change the Application Language - ✅
7. Ability to Change the Theme - ✅
